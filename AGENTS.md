# Món a mà

- Publica cada iteració a `main` de `aaronFortuno/mon-a-ma` i verifica l’estat del desplegament de GitHub Pages.
- Incrementa la versió visible al peu del web, actualitza el resum del quadre de versions a `docs/index.html` i afegeix l’entrada corresponent a `CHANGELOG.md`.
- Quan es proposin temes i apartats nous, tracta’n els títols com a orientatius. Redacta títols propis, clars per a l’alumnat i ajustats al contingut de cada fitxa. Conserva els termes curriculars i de l’àrea quan ajudin a identificar què es treballa.
- En validar fitxes amb taules, comprova la previsualització i la impressió en A4 de totes les variants de lectura. Dona prou amplada a la primera columna per llegir cada paraula sencera i assegura que les etiquetes llargues es pleguen entre paraules. Revisa l’encaix amb els marges i la tipografia per defecte i amb una configuració de lletra més gran.
