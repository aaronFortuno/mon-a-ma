    Un petit espai per explorar el medi

    Món a mà neix d’una necessitat senzilla: tenir apunts i materials imprimibles per preparar carpetes d’aprenentatge i explorar el medi a primària.

    El projecte és gratuït i segueix la filosofia Value for Value: si et resulta útil i vols donar-hi suport, pots fer un microdonatiu voluntari per Lightning. Recomanar-lo també ajuda.

    Adapta la fitxa al teu grup

    Pots triar els apartats, ajustar la maquetació i canviar les imatges abans d’imprimir.

    Al visor, tria Suport, Base o Ampliació per ajustar el text dins del mateix cicle.

    Passa el cursor per sobre d’una imatge o obre Il·lustracions per triar-ne l’estil. En una pantalla tàctil, toca Imatge.

    També hi pots pujar una imatge pròpia i editar-ne el peu i la font. Els teus canvis es desen en aquest navegador.
